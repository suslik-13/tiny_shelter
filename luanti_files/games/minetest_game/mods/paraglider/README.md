# Paraglider [paraglider]

**A standalone Paraglider mod — no Techage dependency required**

![screenshot](https://github.com/joe7575/ta4_paraglider/blob/main/screenshot.png)


This mod is based on the work from m492	 
(https://forum.minetest.net/viewtopic.php?t=24639)


### Instruction

Jump from a hill and use the paraglider to start the flight.  
W = increases speed  
S = decreases speed  
D = right turn  
A = left turn

### Crafting
```
wool:yellow          technic:carbon_cloth       wool:yellow
farming:string       farming:string             farming:string
                     unified_inventory:bag_large
```

### Dependencies
None required. Optional (used only if present): `default`, `wool`, `farming`,
`technic`, `unified_inventory`. The mod no longer depends on Techage and
works on any server without it.
